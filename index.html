Routing

Di Flask, @app.route memetakan URL ke fungsi Python. Di sini peta itu jadi navigasi: klik sebuah route untuk pindah menu, arahkan kursor untuk melihat responsnya.

from flask import Flask

app = Flask(__name__)

@app.route("/")
def home():
    return "Hello, Flask!"

if __name__ == "__main__":
    app.run(debug=True)
Hello World

Satu file sudah jadi aplikasi. Jalankan flask run, buka 127.0.0.1:5000. debug=True hanya untuk pengembangan.

from flask import Flask, jsonify

app = Flask(__name__)

@app.route("/api/user/<int:user_id>")
def get_user(user_id):
    return jsonify(id=user_id, framework="Flask")

from flask import Flask, request, jsonify
import joblib

app = Flask(__name__)
model = joblib.load("model.pkl")

@app.post("/predict")
def predict():
    x = request.get_json()["features"]
    return jsonify(pred=model.predict([x])[0].item())
Deploy Model ML

Muat model sekali saat start, sediakan POST /predict. Untuk produksi pakai Gunicorn: gunicorn -w 4 app:app, bukan server bawaan Flask.
